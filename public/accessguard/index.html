Scores you can audit.

U1 AccessGuard assesses websites for accessibility and security, then publishes the receipts: what ran, what it found, and the hash of the evidence. Below is a full sample, exactly as the engine produced it.

What AccessGuard does.

An assessment is automated checks plus an honest accounting of what automation can't see. Three things it always does.

Method

Passive checks only

Passive security-header observations and axe-core automated checks. No exploitation, no load testing, no access attempts.

Limits

Says what it can't see

Scores are a triage aid computed from automated findings, not a certification. Anything automation can't judge is flagged for manual verification instead of scored as a failure.

Evidence

Hashed, on every report

Every report carries its authorization statement and a SHA-256 evidence hash, so the published result is the result that ran.

What this assessment does not claim

Automated checks cover a portion of the WCAG standard and a defined set of passive security observations. A clean automated result is not full WCAG conformance and not a guarantee of security; items marked "needs manual verification" require a human reviewer. No active exploitation, load testing, or access attempts were performed. Remediation, where purchased, is an explicit scope of work described in the service terms - it is not a promise that a site becomes "100% secure" or "fully accessible."
