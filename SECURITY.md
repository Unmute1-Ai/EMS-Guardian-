# Security Policy

## Reporting a vulnerability

Do not publish exploitable vulnerability details, secrets, PHI, credentials, or incident data in a public issue.

Prefer GitHub private vulnerability reporting / a private security advisory when available. Otherwise contact the repository owner privately through the GitHub account associated with this project.

Include:
- affected commit/version,
- impact,
- minimum reproduction steps,
- whether real user or sensitive data is involved,
- suggested mitigation if known.

## Security boundary

This repository is a production candidate, not a security or regulatory certification. AI output must remain advisory unless a separately authenticated authority integration explicitly permits an effect.

Never commit production secrets or real patient information.
